# SecureIntent — Assessment Documentation

This branch contains the documentation deliverable for the SecureIntent engineering assessment.
It is intentionally separate from both platform implementations and should not be used as the
runtime or installation branch.

## Documentation deliverable

- [`PART2-STRATEGIC-BRIEF.md`](PART2-STRATEGIC-BRIEF.md) — the one-page 12-month roadmap from
  Individual Pro to Enterprise Teams, covering BYOD privacy, decentralized enterprise policy, and
  the market case for local-first DLP.

## Platform branches

- [`main`](https://github.com/0xkaushik-ai/shadow-upload-interceptor-v1/tree/main) — Linux-only
  implementation, setup, systemd lifecycle, testing, and demo instructions.
- [`shadow-upload-interceptor-macos-version`](https://github.com/0xkaushik-ai/shadow-upload-interceptor-v1/tree/shadow-upload-interceptor-macos-version)
  — macOS-only implementation, setup, `launchd` lifecycle, testing, and demo instructions.

The Linux and macOS branches are standalone platform releases. They are not intended to be merged
into each other.
